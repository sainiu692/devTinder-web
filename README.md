
#DevTinder

1. Create a Vite + React application
2. Remove unnecessary code and create a Hello World app
3. Install Tailwind CSS
4. Install Daisy UI
5. Add NavBar component to App.jsx
6. Create a NavBar.jsx separate Component file
7. Install react router dom
8. Create BrowserRouter > Routes > Route=/ Body > RouteChildren
9. Create an Outlet in your Body Component
10. Create a footer
11. Create a Login Page
12. Install axios
13. CORS - install cors in backend => add middleware to with configurations: origin, credentials: true
14. Whenever you're making API call so pass axios => { withCredentials: true }
15. install react-redux + @reduxjs/toolkit - https://redux-toolkit.js.org/tutorials/quick-start
16. configureStore => Provider => createSlice => add reducer to store
17. Add redux devtools in chrome
18. Login and see if your data is coming properly in the store
19. NavBar should update as soon as user logs in
20. Refactor our code to add constants file + create a components folder
